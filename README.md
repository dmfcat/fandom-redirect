# Fandom Redirect

Simple userscript that redirects specific fandom wiki sites to their official counterparts.

## Installing

Install using a userscript manager, [Violentmonkey](https://violentmonkey.github.io/) is recommended.

1. Select install from URL and paste:

```text
https://raw.githubusercontent.com/dmfcat/fandom-redirect/refs/heads/main/fandom-redirect.user.js
```

## Adding More Domains

Support for more domains can easily be achieved, by adding them to the `domains` dictionary.
